## Featured Projects

### NHS A&E Activity Analysis | England

**Tools:** SQL Server · Tableau Public · Excel

Analysed 194 months of NHS England A&E activity data to investigate attendance trends, department-level demand and changes between 2019 and 2025.

**Key findings:**
- Total A&E attendances increased by 8.45% between 2019 and 2025.
- Type 3 attendances increased by 15.07% over the same period.
- Identified and corrected numerical precision loss during SQL data import, successfully validating all 194 monthly records.
